# CSS3HomeworkTwo

CSS3HomeworkTwo is a small static website about springtime walks in Michigan. It includes a homepage plus two photo galleries: one for neighborhood walks and one for park walks. The site is built with plain HTML and CSS, so it can be opened directly in a browser without any build step.

## Pages

- `index.html` - introduction to the site and links to Ann Arbor-related resources
- `neighborhood.html` - a gallery of neighborhood walk photos
- `parks.html` - a gallery of park and nature walk photos

## Features

- Shared navigation across all pages
- Skip link for keyboard accessibility
- Responsive viewport meta tag
- Custom styling in `css/style.css`
- Local image assets stored in `images/`

## Project Structure

```text
CSS3HomeworkTwo/
├── index.html
├── neighborhood.html
├── parks.html
├── css/
│   └── style.css
└── images/
```

## How To Run

1. Open the `CSS3HomeworkTwo` folder in your file explorer or editor.
2. Open `index.html` in a web browser.
3. Use the navigation links to move between the pages.
